# 工作台控制台 UI 设计

## 背景

工作台已有今日批次、研究记录、数据快照、交易日记、复盘中心和对外分享页。
视觉是深青底、宋体大标题、珊瑚主按钮、01/02 装饰编号、9–11px 正文。数字不够
跳，长页主次不清。交易日记虽有账户条和左右栏，仍是同一套编辑气质。

用户要求整站更美观、数据更直观、结构划分更清楚。已确认：覆盖全部工作台页面；
视觉为数据控制台；布局为顶部 KPI 条加左右双栏；盈亏为 A 股红涨绿跌。实现方式为
抽出共用零件再拼装各页，而不是只改 CSS。

## 目标

- 五页工作台加分享页共用同一套色板、数字层级和卡片。
- 关键数字（权益、盈亏、回撤、进度）一眼可读：大号等宽、千分位、带符号、有涨跌色。
- 每页结构固定为：KPI → 左上下文 / 右主操作 → 全宽次要信息。
- 不改变任何 API、账本、报告字段或金额精度。

## 非目标

- 不改后端、路由语义、hash（`#/batch|records|snapshots|journal|reviews|share/...`）。
- 不加功能：线段/背驰、登录、多账户、新图表指标。
- 不把金额字段转成 JavaScript `number`。
- 不做截图像素回归。
- 不把分享页改成工作台双栏；打印仍白底。
- 不把 `App.tsx` 的数据逻辑拆成新状态库。

## 方案选择

采用「控制台零件 + 现有页面拼装」。

未采用只换皮：现有 DOM 顺序无法稳定形成 KPI + 双栏。
未采用按页独立重写视觉：会漂成五套样式。

## 视觉令牌

写在 `apps/web/src/styles.css` 的 `:root`，组件只引用变量。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b0d10` | 页面底 |
| `--surface` | `#161b22` | 卡片 |
| `--border` | `#30363d` | 描边 |
| `--text` | `#e6edf3` | 主文字 |
| `--muted` | `#8b949e` | 标签、说明 |
| `--accent` | `#1f6feb` | 主按钮、选中段控 |
| `--up` | `#f85149` | 涨、盈利、买入标记 |
| `--down` | `#3fb950` | 跌、亏损、卖出标记 |
| `--risk` | `#f0883e` | 回撤、警告、降级质量 |
| `--radius` | `8px` | 卡片和控件 |

字体：系统无衬线（去掉工作台对 Noto Serif SC / 装饰性 DM Mono 标题的依赖）。
数字：`font-variant-numeric: tabular-nums`。KPI 值约 28px，次级约 16px，正文 13px，
标签 11px。

拿掉：宋体英雄标题、珊瑚块状主按钮、01/02 装饰编号、5px 偏移阴影。

侧栏仍在，改成控制台密度：更短品牌字、普通字重、选中项用 `--accent` 而不是珊瑚左边线。

## 展示格式

新增纯展示辅助（例如 `apps/web/src/ui/formatDisplay.ts`），只用于 UI：

- 千分位只加在小数点左侧，保留原小数部分；失败则原样显示。
- 带符号的盈亏：正数前加 `+`，负数保留 `-`，零不带符号。
- `tone`：`up` 红、`down` 绿、`risk` 橙、`neutral` 主文字。
- 当日盈亏、周期盈亏、闭合周期盈亏：正 `up`，负 `down`，零 `neutral`。
- 最大回撤、成立以来回撤：`risk`，不用绿。
- 胜率、纪律率、现金、权益、股数：`neutral`，除非该字段本身是带符号盈亏。
- `null` / 不可用：显示 `—`，`neutral`，不编造 `0`。

接口 JSON 继续用现有字符串。测试里对金额文案的断言若含展示格式，改为匹配格式化后的文本。

## 共用零件

目录：`apps/web/src/ui/`。只建这些，不增加抽象层。

| 零件 | 职责 | 用法 |
|---|---|---|
| `MetricTile` | 标签 + 大数字 + `tone` | KPI 一格 |
| `KpiStrip` | 横向一排 `MetricTile` | 页顶数字 |
| `Panel` | 圆角卡片：可选标题、主体 | 所有区块容器 |
| `SplitPane` | 左约 0.9fr / 右约 1.3fr，≤1100px 单列 | 上下文 vs 主操作 |
| `SegmentedControl` | 互斥选项，沿用 `aria-pressed` | 周期、日线/周线 |
| `DataTable` | 表头/表体样式和空表文案槽 | 持仓、归因、记录 |
| `EmptyState` | 短说明 + 可选下一步 | 无账户、无报告、无持仓 |
| `StatusChip` | 小状态：质量、任务、LIVE | 质量标签、进度 |

`Notice` 继续用现有 `.notice` 角色 `alert`，只换色板。不新造 Banner 组件。

零件测试（薄）：`MetricTile` 正盈亏为红、负为绿、回撤为橙；`formatDisplay` 千分位与符号。
不测 CSS 像素。

## 页面拼装

所有页保留现有标题文字、按钮名称、`aria-label`、表格 `aria-label`，除非某条文案
与展示格式冲突（仅金额千分位）。

### 交易日记

1. 页头：标题「每日交易日记」+ 交易日期。
2. `KpiStrip`：总权益、可用现金、持仓市值、当日盈亏、成立以来回撤。
3. `SplitPane`：左「当前持仓」表；右上成交录入，右下今日流水与资金流水。
4. 全宽「收盘检查」。
5. 无账户：现有创建表单，放进 `Panel`，不显示假 KPI。

### 复盘中心

1. `Panel`：周/月/季/年 `SegmentedControl`、日期、预览/生成。
2. 选中报告且有确定性结果时，`KpiStrip`：报告期已实现盈亏、闭合周期盈亏、周期最大回撤、胜率、纪律执行率。无报告不渲染 KPI 条。
3. `SplitPane`：左报告版本；右图表、买卖理由、交易周期、同类比较。
4. 全宽：结构归因、Pi 总结。
5. 无历史：左栏 `EmptyState`「该周期还没有固化报告。」

### 今日批次

1. `KpiStrip`：自选只数、本批已完成数、运行中数、数据质量（`StatusChip`，非假百分比）。
2. `SplitPane`：左自选池；右本批进度 + 结构报告（图+结论标题）。
3. 全宽：资讯与市场热度、AI 条件展望。
4. 无自选、无报告：右栏 `EmptyState`，不编造结构结论。

### 研究记录

`KpiStrip` 使用质量看板已有计数（总数、失败、降级等现有字段）+ 下方报告表 `DataTable`。
不新增统计口径。

### 数据快照

四个现有快照数字改为 `MetricTile`/`KpiStrip`，来源列表用 `Panel`。计数语义不变。

### 分享页

单栏 `Panel`。屏幕用控制台色板。`@media print` 仍白底黑字，交互按钮隐藏。不使用 `SplitPane`。

## 图表

不改缠论或复盘计算。只改 ECharts 颜色与图例：

- K 线涨 `--up`，跌 `--down`。
- 买入叠加 `--up`，卖出叠加 `--down`。
- 权益线用 `--text` 或 `--accent`，回撤用 `--risk`。
- 笔、中枢保持可辨，避免再引入珊瑚/青绿作为涨跌语义。

## 状态

- 加载：KPI/表用占位块（CSS 即可），按钮 busy 文案保持「正在创建…」「正在生成…」等。
- 错误：工作台顶部 `.notice`；日记/复盘表单内 `role="alert"` 保持。
- 空：无账户、无报告、无持仓用 `EmptyState`。归因在账户存在且无成交时仍展示五类全 0 的真实聚合。

## 响应式

- `≤1100px`：`SplitPane` 单列，KPI 每行最多 3 格。
- `≤700px`：KPI 每行 2 格；侧栏沿用现有窄屏/顶栏行为。
- `≤520px`：表单单列。不新做移动 App 导航。
