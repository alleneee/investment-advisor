# 隐藏结构结论与报告证据展示设计

## 目标

减少研究台重复信息，只保留图表、条件化情景和风险边界。

## 展示调整

- 结构报告不再渲染结构结论、结构事实列表及其右侧容器。
- K 线、成交量、缠论笔与中枢、周期切换、数据来源和质量信息保持不变。
- AI 报告不再渲染顶层“引用证据”区域。
- 三个情景卡片不再渲染“证据”标签及证据条目。
- 三情景正文、触发条件、失效条件、风险边界和免责声明保持不变。
- 独立的资讯与市场热度区域保持不变。
- 数据快照中的已确认、形成中结构计数保持不变；它们是汇总指标，不是本次隐藏的
  结构报告结论区。
- 报告生成进度只描述结构和资讯整理，不再显示“引用证据”文案。

## 数据边界

前端 DTO、Python 水合结果、引用注册表和服务端证据校验保持不变。本次仅停止渲染
指定数据，不删除或修改报告中的证据字段。

## 验证

- 组件测试断言 `.report-copy`、顶层证据区域和 `.scenario-evidence` 不再渲染。
- 组件测试继续断言图表、三情景、触发与失效条件、风险边界正常展示。
- 运行完整前端测试、类型检查、生产构建和 README markdownlint。
