# 周期复盘个股 BS 点分析设计

## 背景

周期复盘已有账户指标、理由矩阵、闭合周期列表，以及一张把账户权益、缠论和
未复权日线买卖点叠在一起的图。用户要对照同花顺「BS点分析」做个股复盘：先看
本周期股票盈亏块，点进去看该股日线和 30 分钟 K 线，实盘成交自动打 B/S，并在
任意 K 线上标记自己的理想买卖、高低位和复盘想法，副图只画成交量和 MACD。

现有 `chartBundles` 冻在确定性报告里，只有日线，不能点选，也没有独立于报告
版本的手标层。30 分钟行情通道已在缠论复盘和 `minutes(freq=30m)` 中存在，交易
复盘图尚未使用。

## 已确认需求

- 入口在周期复盘（周/月/季/年），布局为同花顺式：盈亏块 → 个股 BS 分析。
- 个股页标签：`BS点分析` | `交易记录`；周期切换：`日线` | `30分钟`。
- 图从上到下：K 线（可点选）→ 成交量 → MACD（DIF / DEA / 红绿柱）。
- 实盘 B/S 仅来自成交账本，用来复盘是否成功、是否守纪律、收益率和成功率。
- 任意一根 K 线都可打点位类型 + 自定义评论；同一根可叠多条。
- 预置类型：理想买、理想卖、高点、低点、复盘点；允许自建类型（名称、字母、颜色）。
- 日线与 30 分钟共用一套手标（按时间戳投影）；手标跟账户下的股票时间轴走，
  不绑定某一份报告版本。
- 手标不进账本，不改持仓、现金、已实现盈亏或成功率。
- 这张图不叠账户权益、缠论笔/中枢、均线、每日盈亏、金叉死叉或背驰。

## 目标

- 在周期复盘中按股票展示本周期已实现盈亏块，并进入该股 BS 分析。
- 日线和 30 分钟未复权 K 线上叠加实盘成交与手标。
- 提供手标和自定义类型的读写，任意 K 线可叠加多条类型+评论。
- 对当前图的未复权收盘计算 MACD(12,26,9)，样本不足时明确未就绪。
- 个股成功率、建清仓次数、持仓天数中位数只统计本周期已闭合交易周期。

## 非目标

- 不在这张图上画缠论笔、中枢、一类买卖点、背驰、金叉或死叉。
- 不画均线和每日盈亏副图。
- 不在图上新增、修改或删除成交。
- 不把手标冻进确定性报告快照，也不让 Pi 读取手标评论。
- 不开放 15 分钟或 60 分钟 BS 分析。
- 不把未实现浮盈计入盈亏块。
- 不支持多账户。
- 不替换交易日记的成交录入流。

## 方案选择

采用「账本成交 + 独立图标注记层 + 周期窗口统计」：

1. 成交仍只通过交易日记写入账本；图上实心 B/S 是成交投影。
2. 手标是账户内按股票和时间保存的日记，CRUD 不经过报告快照。
3. 周期复盘只提供窗口：哪些股票进盈亏块、成功率用哪一段闭合周期、默认缩放到哪。
4. 个股 K 线、成交量、MACD、手标在打开 BS 分析时实时读取，不写入 `chartBundles`。

未采用把标注塞进现有 `chartBundles`：换一份周报/月报或重生快照会对不齐，违背
「跟股票时间轴走」。未采用仅浏览器本地存储：换设备即丢失，也无法和周期统计同页。

周期复盘主区不再渲染现有「权益、回撤与真实买卖点」大图，避免与 BS 分析抢主图。
确定性报告仍可生成 `chartBundles`（旧接口与测试保持），本页前端不画它。账户指标带
保留在盈亏块上方。

## 页面结构

周期选择、预览/生成确定性复盘、账户指标带保持现有位置。有本周期成交后，主区
展示：

1. 股票盈亏块（面积或宽度按已实现盈亏绝对值，盈利红 `#f6465d`、亏损绿
   `#0ecb81`、零盈亏中性 `#bbcbb2` 且使用同一最小面积）。
2. 选中股票后：名称、代码、`BS点分析` / `交易记录`、`日线` / `30分钟`。
3. BS 图：K 线、成交量、MACD；默认缩放对准本周期，周期外 K 线仍可看。
4. 本股三个数：建清仓次数、平均持仓（中位数）、交易成功率。
5. 交易记录 tab：该股本周期成交列表；点一行把十字线移到对应 K 线，不打开改账本。

没有成交时盈亏块为空态，不展示假股票。未点选股票时不画个股图。

## 领域模型

### 手标 `ChartMark`

账户内一条图标注记，不属于报告版本。

| 字段 | 含义 |
|------|------|
| `mark_id` | 稳定 ID |
| `account_id` | 单账户 |
| `symbol` | 沪深代码，与成交同一校验 |
| `occurred_at` | 用户点击的那根 K 的时间，Asia/Shanghai |
| `type_id` | 点位类型 |
| `comment` | 自定义评论，可空，最长 1000 字（与成交备注上限一致） |
| `revision` | 乐观并发 |

同一 `(account_id, symbol, occurred_at, type_id)` 允许重复行，用 `mark_id`
区分，以便同一根 K 上叠多条同类或不同类评论。

创建时客户端必须提交图表返回的某根 K 的 `occurred_at`，服务端校验该时点在
对应周期（日线或 30 分钟）的已返回 K 线上存在；K 线不存在则拒绝，避免钉在
假柱上。列表查询不要求 K 线仍在：日线缺失时仍可列出历史手标，但不能新钉。

### 点位类型 `ChartMarkType`

| 字段 | 含义 |
|------|------|
| `type_id` | 稳定 ID |
| `account_id` | 账户 |
| `code` | 账户内唯一短码 |
| `label` | 显示名 |
| `letter` | 图上 1–2 个字符 |
| `color` | 十六进制颜色 |
| `preset` | 是否预置 |
| `enabled` | 停用后不能再选，已有手标仍按原类型展示 |

预置五类，账户首次使用 BS 分析时写入，不可删除：

| code | label | letter | color |
|------|-------|--------|-------|
| `ideal_buy` | 理想买 | 买 | `#f6465d` |
| `ideal_sell` | 理想卖 | 卖 | `#4a90e2` |
| `high` | 高点 | 高 | `#f5a623` |
| `low` | 低点 | 低 | `#7ed321` |
| `review` | 复盘点 | 复 | `#9b8cff` |

自建类型：名称、字母、颜色必填；`code` 由服务端生成稳定短码。预置可停用、
不可删。自建类型若仍被手标引用则拒绝删除，需先改类型或删点。类型重名
（同一账户下 `label` 或 `letter` 冲突）拒绝保存，不静默合并。

实盘成交不占用这些类型。图上实心 `B` / `S` 只表示账本买入/卖出。

### 时间投影

手标只存 `occurred_at`，不存 timeframe。现有未复权日线柱的 `occurred_at` 是上海
日历日 `00:00:00+08:00`，30 分钟柱是盘中 `trade_time`，因此不能用「时间戳全等」
同时对准两套柱。

投影规则：

- **日线图**：上海日历日相同的手标全部叠在当天日 K；点击日 K 列出当天全部点。
- **30 分钟图**：若存在 `occurred_at` 等于柱时间的 30 分 K，钉在那根；否则钉在
  **同一上海日历日的最后一根 30 分 K**（日线点击产生的点出现在尾盘柱，不复制到
  当天每一根 30 分 K）。该日没有任何 30 分柱时，30 分钟图不画该点，日线仍画。
- **在日 K 上新建**：`occurred_at` 取该日 K 的 `occurred_at`（日线午夜时点）。
- **在 30 分 K 上新建**：取该 30 分柱时间。切到日线后出现在当天日 K。

实盘成交按 `executed_at` 投影：日线用成交的上海日历日；30 分钟按 provider 返回
顺序，第 i 根覆盖 `(occurred_at[i-1], occurred_at[i]]`，第一根覆盖
`(occurred_at[0] - 30 minutes, occurred_at[0]]`。没有覆盖柱时只在日线显示。

## 统计口径

手标不进入下列任何数字。开放周期不进入成功率、建清仓次数和平均持仓。

| 展示 | 口径 |
|------|------|
| 盈亏块成员 | 本周期内至少一笔成交的股票，包括本周期只有买入、已实现盈亏为 0 的股票 |
| 块金额 | 该股本周期已实现盈亏（按卖出确认，与现有「报告期已实现盈亏」同口径，按 `symbol` 切开）。金额为 0 的块仍展示，使用同一最小面积，不按 0 缩成看不见 |
| 建清仓次数 | 清仓日落在本周期的闭合周期数 |
| 平均持仓 | 上述闭合周期的持有交易日中位数 |
| 交易成功率 | 盈利闭合周期数 / 闭合周期数；分母为 0 时值为 `null`，界面显示「—」 |

账户级指标带继续使用现有确定性复盘结果，口径不变。

盈亏块和个股三个数在周期预览或已生成报告之后计算，与当前复盘窗口
`period_start` / `period_end` 一致，不另开一套日期规则。

## 行情与 MACD

BS 分析 K 线、成交量、MACD 一律**未复权**（`adjustment=none`），与成交价和现有
交易复盘图一致。投研报告的前复权日/周线不用于这张图。

- 日线：现有未复权日线缓存/provider；窗口覆盖本周期，并向前多取，保证
  MACD 热身至少 35 根（26+9），默认再留一段周期前文。
- 30 分钟：`provider.minutes(symbol, freq="30m", ...)`，与缠论复盘同一分钟通道；
  同花顺路径分钟线仍回退 Tushare。向前约 25 个交易日。失败时该股 30 分钟
  `available=false`，日线不受影响。
- MACD：对**当前图返回的未复权收盘**调用现有 `compute_macd`（EMA 12/26/9，
  柱值 `2 * (DIF - DEA)`）。该函数在现有 `histogram` 之外增加与输入等长的
  `dif`、`dea` 十进制字符串数组。热身期之前的位置**保持当前垫值算法**，不改成
  `null`，以免缠论直方图面积变化。`ready=false`（根数不足 35）时 `dif`/`dea`/
  `histogram` 仍为空列表，BS 副图整块占位「MACD 未就绪」，不画半截柱。
  `ready=true` 时副图绘制全序列。缠论背驰只读 `histogram`，判定规则不变。

默认 `dataZoom` 对准本周期首末交易日；周期外的柱和更早手标仍在全量数据里。

## API 草案

前缀与现有交易 API 相同，单账户，浏览器不传账户 ID。金额与价格继续用十进制
字符串。时间用带时区的 ISO-8601。

### 周期个股摘要

`GET /api/trading/bs-summary?start=&end=`

在已能取得该窗口账本结果的前提下返回：

```json
{
  "start": "2026-08-01",
  "end": "2026-08-31",
  "symbols": [
    {
      "symbol": "002041.SZ",
      "name": "登海种业",
      "realized_pnl": "4377.88",
      "closed_cycle_count": 2,
      "median_holding_days": { "value": "13", "unavailable_reason": null },
      "win_rate": { "value": "1", "unavailable_reason": null }
    }
  ]
}
```

`win_rate` / `median_holding_days` 在没有闭合周期时 `value` 为 `null`，
`unavailable_reason` 为 `no_closed_cycle`。没有成交则 `symbols` 为空数组。

### 个股图

`GET /api/trading/bs-chart?symbol=&timeframe=1d|30m&start=&end=`

返回未复权 `bars`、本窗口可投影的 `executions`、`macd`、`quality`。
`timeframe=30m` 且上游失败时 HTTP 仍 200，`available=false`，`bars=[]`，
`quality.status=unavailable`。日线缺失同样 200 + `available=false`，不 500。

### 手标与类型

- `GET /api/trading/chart-mark-types`
- `POST /api/trading/chart-mark-types` 创建自建类型
- `PATCH /api/trading/chart-mark-types/{type_id}` 改标签/字母/颜色/启用
- `DELETE /api/trading/chart-mark-types/{type_id}` 仅自建且未被引用
- `GET /api/trading/chart-marks?symbol=&start=&end=`
  `start`/`end` 必须覆盖**图表实际返回的 K 线窗口**（含周期前文/30 分钟 lookback），
  不能只传复盘 `period_start`/`period_end`，否则周期外可见柱上的手标会被丢掉。
- `POST /api/trading/chart-marks` 体含 `symbol`、`occurred_at`、`type_id`、`comment`、
  `timeframe`（仅用于校验该柱存在）
- `PATCH /api/trading/chart-marks/{mark_id}` 改类型或评论，需 `revision`
- `DELETE /api/trading/chart-marks/{mark_id}` 需 `revision` 或与现有成交删除一致的
  冲突处理

错误码沿用交易模块风格：`INVALID_REQUEST`、`REVISION_CONFLICT`、
`MARK_TYPE_IN_USE`、`MARK_TYPE_PRESET`、`BAR_NOT_FOUND`、`DUPLICATE_TYPE`。

保存失败时前端不把点画成已钉上，评论留在输入框，展示安全错误摘要。

## 失败态

- 本周期无成交：盈亏块空态。
- 日线不可用：个股日线图空态 + 行情不可用；手标列表仍可读；禁止在日线上新建。
- 仅 30 分钟不可用：日线可用；30 分钟 tab 说明不可用；禁止在 30 分钟新建。
- MACD 未就绪：K 线与点正常，副图占位「MACD 未就绪」。
- 类型重名或删除仍被引用：拒绝，不静默合并或级联删点。
- 行情柱不存在：`BAR_NOT_FOUND`，不创建手标。

## 测试要点

- 已实现盈亏按股票切开后之和等于账户本周期已实现盈亏。
- 成功率分母不含开放周期；手标增删不改变任何统计字段。
- 30 分标记出现在对应日 K；日 K 新建的点在 30 分钟图上只出现在该日最后一根
  30 分 K，不复制成当天每一根，也不是「30 分钟图上完全看不见」。
- 同一 `occurred_at` 多条手标全部返回并全部绘制。
- `compute_macd` 增加 `dif`/`dea` 后，既有直方图与面积测试仍通过。
- 30 分钟 provider 失败时摘要和日线图仍 200。
- 预置类型不可删；自建类型在引用存在时不可删；重名 400。
- 前端：盈亏块点选（含零盈亏中性色）、日线/30 分钟切换、点 K 提交、一根多条、
  MACD 未就绪文案。

## 做完标准

选周期并预览或生成复盘后：能看到本周期有成交股票的盈亏块；点入个股后日线与
30 分钟可切换；实盘 B/S 自动出现；任意存在的 K 可打类型+评论且可叠多条、两图
同步、可自建类型；MACD 有柱或明确未就绪；成功率和盈亏只随成交变化。
