# 报告 PDF 与长图导出设计

## 背景

当前“导出 PDF”只存在于 `#/share/{token}` 对客分享页顶部。今日批次页的“对客交付”
只显示分享链接和复制操作，没有明确的打开入口，因此用户在 `#/batch` 无法直接看到导出
功能。

分享页已经通过浏览器打印完成 PDF 导出，并在打印前将 Lightweight Charts 画布转换为
图片。当前没有整份报告的长图生成与下载能力。

## 目标

- 在今日批次页的“对客交付”区域提供“打开对客报告”入口。
- 在对客分享页顶部并排显示“导出 PDF”和“导出长图”。
- 长图包含完整报告正文和缠论图表，不包含导出操作按钮。
- 下载 PNG 时提供明确的处理中状态和失败提示。
- 保留现有 PDF 打印行为、分享链接复制和撤销行为。

## 非目标

- 不在今日批次工作台直接截取整个工作台页面。
- 不修改后端接口、分享令牌或报告数据结构。
- 不生成服务端文件，不上传或持久化导出结果。
- 不调整报告正文、图表数据或 PDF 分页。
- 不引入额外的文件保存库。

## 方案

采用“批次页打开报告，分享页统一导出”的方案。

### 批次页入口

报告已发布且存在分享令牌时，在“分享链接”操作区增加“打开对客报告”链接。链接复用
现有 `shareUrl` 生成规则，在新标签页打开 `#/share/{token}`，并保留现有复制链接和撤销
分享操作。

这样不会在工作台的复杂布局上重复实现导出，也能让对客报告保持唯一的导出内容来源。

### 分享页操作区

分享页页头右侧改为独立操作区，包含：

- “导出 PDF”：继续调用 `window.print()`。
- “导出长图”：把 `.share-report` 根节点转换为 PNG Blob 并触发浏览器下载。

移动端沿用页头纵向排列，操作按钮保持并排或自然换行，不遮挡标题和元数据。

### 长图生成

新增 `html-to-image` 依赖，使用其 `toBlob` API转换报告根节点。导出参数固定为：

- 使用报告页面当前深色背景。
- `pixelRatio` 为 2，保证文字和图表清晰。
- `cacheBust` 为 `true`，避免外部字体或资源使用旧缓存。
- 通过 `filter` 排除带有 `data-export-ignore` 的操作区。

Blob 生成后创建临时对象 URL，用隐藏下载链接保存为
`{股票代码}-{数据日期}-研究报告.png`，随后释放对象 URL。若浏览器返回空 Blob 或生成
失败，页面显示“长图导出失败，请稍后重试。”，不影响 PDF 和正文浏览。

Lightweight Charts 当前由 Canvas 渲染，`html-to-image` 会在克隆 DOM 时复制 Canvas
像素，因此长图直接保留图表，不复用仅面向打印媒体的临时图片。

## 状态与交互

- 点击“导出长图”后按钮文案切换为“正在导出…”，并在完成前禁用。
- 导出期间不阻塞“导出 PDF”。
- 再次导出前清除上一次错误。
- 导出操作区不会出现在 PNG 中。
- “打开对客报告”使用真实链接，支持键盘访问和浏览器原生新标签页行为。

## 实现范围

- `apps/web/package.json` 和 `apps/web/package-lock.json`：增加 `html-to-image`。
- `apps/web/src/SharedReportPage.tsx`：增加报告节点引用、长图导出状态和下载操作。
- `apps/web/src/SharedReportPage.test.tsx`：覆盖 Blob 下载、文件名、处理中状态与失败提示。
- `apps/web/src/OutlookPanel.tsx`：增加“打开对客报告”链接。
- `apps/web/src/OutlookPanel.test.tsx`：覆盖入口的地址与新标签页属性。
- `apps/web/src/styles.css`：增加分享页操作区和链接样式。
- `README.md`：说明导出入口和支持格式。

不得还原或重写 `App.tsx`、`App.test.tsx`、`styles.css` 中已有的工作区改动。

## 测试与验收

### 自动化测试

- 分享页渲染两个导出按钮。
- PDF 按钮仍调用一次 `window.print()`。
- 长图按钮调用 `toBlob`，排除操作区，并下载正确文件名的 PNG。
- 长图生成期间按钮禁用且显示“正在导出…”。
- `toBlob` 失败或返回空值时显示中文错误。
- 已有分享令牌时显示“打开对客报告”，地址正确且在新标签页打开。
- 没有分享令牌时不显示该入口。

### 浏览器验收

- 从 `#/batch` 的“对客交付”可以打开分享报告。
- 分享页顶部能直接看到两个导出按钮。
- 下载得到的 PNG 可以打开，包含完整报告和图表，不包含按钮。
- PNG 的文字、卡片边框和图表没有明显截断或错位。
- PDF 导出仍可用。
- 页面控制台无新增错误。
